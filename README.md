# Homebrew tap for Otium

Formulae for [Otium](https://getotium.ai)'s tools, written by each tool's release.

```sh
brew install getotium/tap/otiumctl
```

- `otiumctl`: the command-line client ([getotium/otiumctl](https://github.com/getotium/otiumctl)).

Don't edit the formulae by hand: the next release overwrites them.
